# ML Community Platform - Полная интегрированная платформа

Комплексная платформа для сообщества Mobile Legends: Bang Bang с полным функционалом и русской локализацией.

## 🎯 Обзор платформы

**ML Community Platform** - это полнофункциональная веб-платформа для фанатов Mobile Legends: Bang Bang, объединяющая:
- 🦸 **База данных героев** (57 героев с полными описаниями)
- 📚 **Система гайдов** и сборок
- 👥 **Пользовательские профили** с статистикой
- 🏆 **Система достижений** и геймификация
- ❤️ **Избранное** и персонализация
- 🔔 **Уведомления** в реальном времени
- 📊 **Детальная аналитика** и статистика

## 🚀 Ключевые возможности

### 🦸 База данных героев (57 героев)
- **Tank**: 8 героев - защитники команды
- **Fighter**: 12 героев - универсальные воины  
- **Assassin**: 8 героев - убийцы с высоким уроном
- **Mage**: 13 героев - магические дамагеры
- **Marksman**: 10 героев - дальнобойные стрелки
- **Support**: 6 героев - поддержка команды

**Каждый герой содержит:**
- ✅ Полное имя и титул на русском языке
- ✅ Детальное описание способностей
- ✅ История персонажа (лор)
- ✅ Боевые характеристики (HP, атака, защита, скорость)
- ✅ Актуальная мета-статистика (винрейт, пикрейт, банрейт)
- ✅ Автоматические ссылки на изображения

### 📚 Система контента
- **Гайды по героям** с детальными сборками
- **Новости** и обновления игры
- **Поиск** по всему контенту платформы
- **Комментарии** и рейтинговая система

### 👥 Пользовательские функции
- **Регистрация и аутентификация** пользователей
- **Профили** с детальной статистикой активности
- **Избранное** для героев и гайдов
- **Персональные достижения** и прогресс

### 🏆 Геймификация
- **12 базовых достижений** в разных категориях:
  - Создание гайдов (Первый гайд, Автор, Эксперт, Мастер)
  - Социальная активность (Комментарии, лайки, популярность)
  - Активность (просмотры, рейтинги, щедрость)
- **Система очков** за достижения
- **Прогресс-трекинг** пользовательской активности

### 🔔 Система уведомлений
- **Лайки** на гайды и комментарии
- **Новые комментарии** к вашему контенту
- **Получение достижений**
- **Системные уведомления**
- **Счетчик непрочитанных** в навигации

## 🛠️ Техническая архитектура

### Backend (FastAPI)
- **FastAPI** - современный Python веб-фреймворк
- **SQLAlchemy** - ORM для работы с базой данных
- **PostgreSQL** - основная база данных
- **Alembic** - система миграций
- **Redis** - кэширование и сессии (опционально)
- **JWT** - аутентификация пользователей

### Frontend (Server-side rendered)
- **Jinja2** - шаблонизатор HTML
- **Tailwind CSS** - современный CSS фреймворк
- **Lucide Icons** - иконки для интерфейса
- **JavaScript** - интерактивность (избранное, уведомления)
- **Responsive Design** - адаптивность для всех устройств

### База данных
**Основные модели:**
- `User` - пользователи системы
- `Hero` - герои Mobile Legends
- `BuildGuide` - гайды по сборкам
- `News` - новости и обновления
- `Comment` - комментарии к контенту

**Расширенные модели:**
- `UserStatistic` - статистика пользователей
- `UserFavorite` - избранное пользователей
- `Achievement` - система достижений
- `Notification` - уведомления
- `GuideRating` - рейтинги гайдов

## 📦 Установка и развертывание

### Автоматическая установка
```bash
# Клонируйте репозиторий
git clone https://github.com/Militaryfocus/militaryfocus_frontend.git
cd militaryfocus_frontend/ml-community-monolith

# Запустите автоматическую установку
chmod +x one_click_install.sh
./one_click_install.sh
```

**Скрипт автоматически:**
1. ✅ Обновляет систему
2. ✅ Устанавливает зависимости (Python, PostgreSQL, Redis)
3. ✅ Настраивает базу данных
4. ✅ Создает виртуальное окружение
5. ✅ Устанавливает Python пакеты
6. ✅ Выполняет миграции базы данных
7. ✅ Создает базовые достижения
8. ✅ Импортирует всех героев (57 героев)
9. ✅ Создает администратора
10. ✅ Запускает приложение

### Docker развертывание
```bash
# Запуск с Docker Compose
docker-compose up -d

# Инициализация данных
docker-compose exec app python create_achievements.py
docker-compose exec app python import_heroes.py import
```

### Ручная установка
```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Настройте базу данных PostgreSQL
createdb ml_community
# Настройте пользователя и права

# 3. Выполните миграции
alembic upgrade head

# 4. Создайте достижения
python create_achievements.py

# 5. Импортируйте героев
python import_heroes.py import

# 6. Создайте администратора
python create_admin.py

# 7. Запустите приложение
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 🔄 Обновления и поддержка

### Добавление новых героев
1. Обновите соответствующий JSON файл в `data/`
2. Запустите `python import_heroes.py import`
3. Новые герои автоматически добавятся в базу

### Создание новых достижений
1. Отредактируйте `create_achievements.py`
2. Добавьте новые достижения в список
3. Запустите скрипт для обновления

### Резервное копирование
```bash
# Создание бэкапа базы данных
pg_dump ml_community > backup.sql

# Восстановление из бэкапа
psql ml_community < backup.sql
```
