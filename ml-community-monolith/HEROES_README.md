## 📋 Характеристики каждого героя

Каждый герой содержит:
- **Основная информация**: Имя, титул, роль, специализация, сложность
- **Описание**: Подробное описание способностей на русском
- **Лор**: История персонажа и предыстория
- **Характеристики**: HP, Mana, Physical Attack, Magic Power, Armor, Magic Resistance
- **Боевые параметры**: Attack Speed, Movement Speed
- **Статистика**: Win Rate, Pick Rate, Ban Rate
- **Изображения**: Автоматически генерируемые URL для иконок и полных изображений

## 🚀 Использование

### Импорт всех героев
```bash
python import_heroes.py import
```

### Просмотр списка героев
```bash
python import_heroes.py list
```

### Добавление дополнительных героев
```bash
python import_heroes.py add
```

## 🎮 Особенности

- **Полная русификация**: Все описания, имена и лор переведены на русский
- **Актуальная мета**: Статистика винрейтов и пикрейтов отражает текущую мету
- **Детальные характеристики**: Полные боевые характеристики для каждого героя
- **Автоматические изображения**: Система автоматически генерирует URL изображений
- **Гибкая система**: Легко добавлять новых героев через JSON файлы

## 🔄 Обновления

База данных может быть легко обновлена:
1. Добавьте новых героев в соответствующий JSON файл
2. Запустите скрипт импорта
3. Новые герои автоматически добавятся в базу данных
