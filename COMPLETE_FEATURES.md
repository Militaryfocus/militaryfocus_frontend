## 🔐 БЛОК 1: Аутентификация и пользователи

### 1.1 Регистрация (RegisterPage.tsx - 292 строки)

**Полная форма регистрации с валидацией:**

✅ **Обязательные поля:**
- **Email** - с проверкой формата (`name@domain.com`)
- **Username** - 3-20 символов, только латиница, цифры, `_` и `-`
- **Password** - минимум 6 символов
- **Подтверждение пароля** - должен совпадать

✅ **Опциональные поля:**
- **IGN** (In-Game Name) - игровой ник в Mobile Legends
- **Текущий ранг** - выбор из списка:
  - Warrior, Elite, Master, Grandmaster
  - Epic, Legend, Mythic, Mythical Glory

✅ **Дополнительно:**
- Чекбокс принятия условий использования
- Требования к паролю с подсказками
- Показать/скрыть пароль (оба поля)
- Красивый UI с иконками
- **Автоматический вход** после успешной регистрации

**URL:** `/register`

**API:** `POST /api/v1/auth/register`

```typescript
// Пример использования
const registerData = {
  email: "player@example.com",
  username: "pro_gamer",
  password: "secure123",
  ign: "ProGamer2024",
  current_rank: "Epic"
};

await apiService.register(registerData);
// Автоматически выполняется login
```

### 1.4 Система авторизации (auth.tsx)

**AuthContext с полным управлением сессией:**

✅ **Функции:**
- `login()` - вход в систему
- `register()` - регистрация с автоматическим входом
- `logout()` - выход из системы
- `updateUser()` - обновление профиля
- `isAuthenticated` - статус авторизации
- `user` - данные текущего пользователя

✅ **Роли пользователей:**
- **User** - обычный пользователь
- **Content Creator** - создатель контента
- **Moderator** - модератор
- **Admin** - администратор

✅ **Безопасность:**
- JWT токены (30 минут срок действия)
- Автоматическое обновление токенов
- Хеширование паролей (bcrypt)
- Защита роутов
- Автоматический logout при истечении токена

**API Endpoints:**
```typescript
POST   /api/v1/auth/login          # Вход
POST   /api/v1/auth/register       # Регистрация
GET    /api/v1/auth/me             # Текущий пользователь
POST   /api/v1/auth/refresh        # Обновить токен
POST   /api/v1/auth/logout         # Выход
POST   /api/v1/auth/forgot-password # Восстановление пароля
POST   /api/v1/auth/reset-password  # Сброс пароля
```

## 🎨 БЛОК 2: Конструктор гайдов и контент

### 2.1 Guide Builder (GuideBuilderPage.tsx - 562 строки)

**Визуальный конструктор для создания подробных гайдов:**

#### 🎯 Выбор героя
- **Поиск** по имени и роли
- **Визуальные карточки** с аватарами (120+ героев)
- **Фильтрация** в реальном времени
- Отображение роли и специализации

#### 📝 Основная информация
- **Название гайда*** (обязательно)
- **Описание** - подробное описание стратегии
- **Сложность:** Easy / Medium / Hard
- **Стиль игры:** 
  - Aggressive (агрессивный)
  - Defensive (защитный)
  - Balanced (сбалансированный)
  - Support (поддержка)
  - Pusher (пушер)
- **Боевое заклинание** - выбор из 10:
  - Flicker, Purify, Sprint, Execute, Retribution
  - Inspire, Vengeance, Arrival, Aegis, Petrify

#### ⭐ Настройка эмблем
- **Тип эмблемы:**
  - Custom Mage
  - Custom Marksman
  - Custom Assassin
  - Custom Fighter
  - Custom Tank
  - Custom Support
- **Уровень:** 1-60 (слайдер)
- **3 таланта:**
  - Талант 1 (первый уровень)
  - Талант 2 (второй уровень)
  - Талант 3 (основной талант)

#### 🛡️ Сборка предметов
Разделена по фазам игры:
- **Early Game** (ранняя игра, 0-10 минут)
- **Mid Game** (средняя игра, 10-20 минут)
- **Late Game** (поздняя игра, 20+ минут)

*Примечание: сейчас предметы вводятся по ID, визуальный селектор - в планах*

#### 🏷️ Система тегов
- Добавление неограниченного количества тегов
- Удаление тегов
- Автодополнение (в планах)

#### 🔧 Функции редактора
- **Режим предпросмотра** - посмотреть как будет выглядеть гайд
- **Сохранить черновик** - сохранить незавершенный гайд (is_published: false)
- **Опубликовать гайд** - сделать доступным для всех (is_published: true)
- **Редактирование** - изменить существующий гайд

**URL:**
- `/guides/builder` - создание нового
- `/guides/builder/:id` - редактирование существующего

**Требования:**
- Пользователь должен быть авторизован
- Любая роль может создавать гайды

**API:**
```typescript
// Создание
POST /api/v1/guides

// Редактирование
PUT /api/v1/guides/:id

// Пример данных
{
  hero_id: 5,
  title: "Полный гайд по Fanny для новичков",
  description: "Детальный гайд с объяснением механик",
  battle_spell: "Flicker",
  play_style: "Aggressive",
  difficulty: "Hard",
  tags: ["assassin", "jungle", "advanced"],
  emblems: {
    type: "Custom Assassin",
    level: 60,
    talents: {
      talent1: "Bravery",
      talent2: "Invasion",
      talent3: "Killing Spree"
    }
  },
  item_build: {
    early_game: [1, 2, 3],
    mid_game: [4, 5, 6],
    late_game: [7, 8, 9]
  },
  is_published: true
}
```

**Полная страница просмотра гайда с взаимодействием:**

#### 📄 Заголовок гайда

- Автор (с ссылкой на профиль)

- **⭐ Рейтинг** - средний рейтинг (0.0-5.0)
- **💬 Оценки** - количество оценок

#### ⭐ Форма оценки гайда
**Кнопка "Оставить оценку"** открывает форму:
- **Интерактивные звезды:**
  - Hover эффект (подсвечиваются при наведении)
  - Клик для выбора (1-5 звезд)

- **Текстовый отзыв** (опционально, textarea)

- Кнопка с иконкой сердца
- Заполненное сердце = уже лайкнули
- Клик для лайка/анлайка
- Обновление счетчика в реальном времени
- Требуется авторизация

#### 📋 Детали сборки

**Эмблемы (карточка):**
- Тип эмблемы
- Уровень
- 3 таланта

**Боевое заклинание (карточка):**
- Название заклинания
- Красивое оформление с градиентом

**Сборка предметов (большая карточка):**
- 3 колонки: Early / Mid / Late game
- Визуальные карточки предметов
- Цветовое кодирование (зеленый/желтый/красный)

#### 🔧 Действия (только для автора/админа)
- **Редактировать** - переход в Guide Builder
- **Удалить** - с подтверждением

**URL:** `/guides/:id`

**API:**
```typescript
GET  /api/v1/guides/:id        # Получить гайд
POST /api/v1/guides/:id/like   # Лайкнуть
POST /api/v1/guides/:id/rate   # Оценить
```

## 🚀 Быстрый старт

### Установка:

```bash
# Клонировать репозиторий
git clone https://github.com/Militaryfocus/militaryfocus_frontend.git
cd militaryfocus_frontend

# Запустить с Docker
docker-compose up -d

# Или вручную
cd backend && pip install -r requirements.txt
cd ../frontend && npm install && npm start
```

### Первые шаги:

1. **Зарегистрироваться** на `/register`
2. **Войти** на `/login` (или использовать admin/admin123)
3. **Создать гайд** на `/guides/builder`
4. **Посмотреть статистику** на `/statistics`
5. **(Админ)** Управлять на `/admin`

## 🐛 Известные ограничения

### Текущие:
1. **Guide Builder:** выбор предметов по ID (визуальный селектор в разработке)
2. **Admin Panel:** нет модерации комментариев
3. **Statistics:** нет фильтрации по датам
4. **Auth:** нет email верификации
5. **Auth:** нет восстановления пароля через email

### Планируется:
- Визуальный селектор предметов и эмблем
- Drag-and-drop для порядка предметов
- Система комментариев к гайдам
- Email верификация
- 2FA (двухфакторная аутентификация)
- Социальная авторизация (Google, Facebook)
- Фильтры по датам
- Экспорт статистики

## 💡 Примеры использования

### Регистрация и вход:
```typescript
// Регистрация
await apiService.register({
  email: "player@example.com",
  username: "pro_gamer",
  password: "secure123",
  ign: "ProGamer2024",
  current_rank: "Epic"
});

// Автоматический вход после регистрации

// Или вход отдельно
await apiService.login({
  username: "pro_gamer",
  password: "secure123"
});
```

### Создание гайда:
```typescript
const guide = await apiService.createGuide({
  hero_id: 5,
  title: "Полный гайд по Fanny",
  description: "Для начинающих игроков",
  battle_spell: "Flicker",
  difficulty: "Hard",
  play_style: "Aggressive",
  tags: ["assassin", "jungle"],
  emblems: {
    type: "Custom Assassin",
    level: 60,
    talents: {
      talent1: "Bravery",
      talent2: "Invasion",
      talent3: "Killing Spree"
    }
  },
  item_build: {
    early_game: [1, 2, 3],
    mid_game: [4, 5, 6],
    late_game: [7, 8, 9]
  },
  is_published: true
});
```

### Оценка гайда:
```typescript
// Лайк
await apiService.likeGuide(guideId);

// Рейтинг
await apiService.rateGuide(guideId, 5, "Отличный гайд!");
```

### Управление пользователями (админ):
```typescript
// Верификация
await apiService.verifyUser(userId);

// Смена роли
await apiService.changeUserRole(userId, "Content Creator");

// Деактивация
await apiService.deactivateUser(userId);
```
