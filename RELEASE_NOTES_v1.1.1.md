# 🚀 Release Notes - v1.1.1-monolith-fix

## 📅 Дата релиза
**18 октября 2025**

## 🔧 Исправления

### Критическое исправление
- **Исправлена ошибка Alembic** - решена проблема `configparser.InterpolationSyntaxError` при запуске миграций базы данных
- **Исправлен синтаксис** в `alembic.ini`: `%04d` → `%%04d`

### Новые возможности
- **Автоматизированный скрипт установки** - `fix_and_run_migrations.sh`
- **Упрощенный запуск приложения** - `start_app.sh`
- **Шаблон конфигурации** - файл `.env` с настройками по умолчанию
- **Подробная документация** - `FIX_INSTRUCTIONS.md` с инструкциями по устранению неполадок

## 📦 Что включено

### Скрипты
- `fix_and_run_migrations.sh` - автоматическое исправление и настройка
- `start_app.sh` - простой запуск приложения

### Конфигурация
- `.env` - переменные окружения
